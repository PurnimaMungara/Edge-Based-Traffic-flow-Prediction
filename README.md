🚦 Live Edge-Based Traffic Flow Prediction

An AI-powered traffic monitoring and prediction system that combines real-time traffic data with a lightweight LSTM deep-learning model.

📌 Overview

This project monitors live road traffic using the TomTom Traffic Flow API and predicts traffic flow using an LSTM model. Knowledge Distillation is used to create a smaller Student model from a larger Teacher model, making the solution suitable for lightweight and edge-based deployment.

The application is developed with Streamlit and deployed on Streamlit Community Cloud.

✨ Features
🌐 Real-time traffic monitoring
📍 City-based traffic selection
🚗 Current and free-flow speed monitoring
📊 Congestion and traffic-status calculation
🤖 LSTM-based traffic-flow prediction
🧠 Teacher–Student Knowledge Distillation
⚡ TensorFlow Lite model conversion
📈 Actual vs Teacher vs Student comparison
📦 Lightweight edge-ready model
🖥️ Interactive Streamlit dashboard
🧠 Machine Learning

The project uses LSTM for time-series traffic-flow prediction.

Knowledge Distillation transfers knowledge from the larger Teacher model to the smaller Student model.

Model	Parameters	MAE	RMSE
Teacher	118,081	0.0459	0.0580
Student	4,897	0.0449	0.0569

The Student model uses approximately 24× fewer parameters while maintaining comparable performance.

TensorFlow Lite Model Size: ~19.7 KB

🌐 Live Traffic

TomTom provides live road-segment information such as:

Current speed
Free-flow speed
Congestion
Confidence
Traffic status
Approximate delay

Note: The predicted vehicle value is generated by the LSTM model from the project's traffic-flow sequence. It is not an exact vehicle count returned by TomTom.

For deployment, add the same key through Streamlit → Advanced Settings → Secrets.
